# TC-JC-006 — Modelo sin cobertura en la ubicación consultada

## Datos del evaluador
- Nombre: Juan Camilo La Rotta
- Rol / bloque: QA Lead / jc
- Fecha de ejecución: 2026-09-28
- N.º de ejecución (run): 01

## Descripción del caso de prueba
- RF relacionado: RF-07
- Tipo de prueba: Funcional
- Objetivo: Verificar que, si el modelo seleccionado no tiene cobertura o devuelve variables nulas para la ubicación, la aplicación informe la situación y ofrezca volver a "Automático" sin romper la interfaz.
- Precondiciones: Mock configurado para simular el modelo ICON devolviendo variables nulas para la ubicación de prueba.

## Ambiente
- Nombre: QA
- URL: https://app-clima-local.vercel.app
- Commit / versión evaluada: v1.0.0
- Herramienta: Playwright

## Paso a paso ejecutado
1. Seleccionar el modelo ICON (`icon_seamless`) para la ubicación Neiva cuya respuesta simulada contiene variables nulas.
2. Verificar la presencia del mensaje informativo "El modelo ICON no tiene datos para esta ubicación. Se muestran los datos disponibles o puede volver a Automático."
3. Verificar la presencia del botón / opción "Volver a Automático".
4. Activar la opción "Volver a Automático" y confirmar la restauración de los datos con el modelo por defecto.

## Comando(s) de ejecución
```bash
npx playwright test qa/casos/jc/TC-JC-006/TC-JC-006.spec.ts --config=qa/playwright.config.ts --project=jc
```

## Resultado esperado
Se muestra: "El modelo [NOMBRE] no tiene datos para esta ubicación. Se muestran los datos disponibles o puede volver a Automático."
La opción "Volver a Automático" funciona correctamente y restaura los datos.
La interfaz no se rompe en ningún momento del flujo.

## Resultado obtenido
La prueba falló. Al seleccionar el modelo ICON (`icon_seamless`) con una respuesta HTTP 200 con variables nulas (`temperature_2m: null`, `weather_code: null`), la aplicación renderizó los campos como "N/D" y "Condición no disponible", pero **NO mostró el mensaje de advertencia** "El modelo ICON no tiene datos para esta ubicación..." ni presentó el botón/opción "Volver a Automático" para permitir al usuario restablecer el modelo de predicción.

## Estado
**Fallido**

- Bug asociado (Excel/GitHub): `BUG-JC-006`
