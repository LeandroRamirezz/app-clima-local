## Descripción del caso de prueba
- RF relacionado: RF-07
- Tipo de prueba: Integración
- Objetivo: Verificar que el usuario pueda elegir cada uno de los 4 modelos numéricos disponibles y que el parámetro `models` se envíe correctamente, reflejándose en los datos mostrados y en el indicador de modelo activo.
- Precondiciones: Ubicación activa válida (Neiva). Sección "Opciones avanzadas" colapsada por defecto con "Automático" (`best_match`) seleccionado.

## Ambiente
- Nombre: QA
- URL: https://app-clima-local.vercel.app
- Commit / versión evaluada: v1.0.0
- Herramienta: Playwright

## Paso a paso ejecutado
1. Abrir "Opciones avanzadas" y confirmar que el modelo por defecto es "Automático" (`best_match`).
2. Seleccionar ICON y verificar que la solicitud incluya `models=icon_seamless` y el indicador cambie a "Modelo: ICON".
3. Seleccionar GFS y verificar que la solicitud incluya `models=ncep_gfs_seamless` y el indicador cambie a "Modelo: GFS".
4. Seleccionar ECMWF y verificar que la solicitud incluya `models=ecmwf_ifs025` y el indicador cambie a "Modelo: ECMWF".
5. Confirmar que los datos mostrados en pantalla se actualizan y responden a la respuesta de la API para cada modelo.

## Comando(s) de ejecución
```bash
npx playwright test qa/casos/jc/TC-JC-005/TC-JC-005.spec.ts --config=qa/playwright.config.ts --project=jc
```

## Resultado esperado
En los 4 casos, la solicitud incluye el parámetro `models` correcto.
El indicador de modelo activo se actualiza visiblemente en cada selección.
Los datos mostrados coinciden 100% con la respuesta de la API para el modelo elegido.

## Resultado obtenido
La prueba se ejecutó con éxito. Se verificó que al cargar la aplicación el modelo seleccionado por defecto es "Automático" (`best_match`). Al seleccionar secuencialmente ICON, GFS y ECMWF desde las Opciones Avanzadas, la aplicación realizó en cada caso la petición `GET /v1/forecast` con los parámetros de modelo correspondientes (`icon_seamless`, `ncep_gfs_seamless`, `ecmwf_ifs025`), actualizando en pantalla el indicador de modelo activo y refrescando los datos del clima.
