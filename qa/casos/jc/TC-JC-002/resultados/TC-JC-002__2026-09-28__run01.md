# TC-JC-002 — Configuración del rango de pronóstico (1–16 días) y validación de límites

## Descripción del caso de prueba
- RF relacionado: RF-01
- Tipo de prueba: Funcional
- Objetivo: Verificar que el usuario pueda configurar el rango del pronóstico entre 1 y 16 días (7 por defecto) y que un valor fuera de ese rango se corrija automáticamente al límite permitido.
- Precondiciones: Ubicación activa válida (Neiva). Ambiente QA operativo. Mock dinámico de `/v1/forecast` capaz de responder con la cantidad de días solicitados.

## Ambiente
- Nombre: QA
- URL: https://app-clima-local.vercel.app
- Commit / versión evaluada: v1.0.0
- Herramienta: Playwright

## Paso a paso ejecutado
1. Cargar la aplicación y establecer Neiva como ubicación activa.
2. Verificar que por defecto el input "Días de pronóstico" contenga el valor 7 y se muestren exactamente 7 días en el panel.
3. Cambiar el valor del rango a 1 día y verificar que la interfaz muestre solo el día actual.
4. Cambiar el valor del rango a 16 días y verificar que la interfaz muestre los 16 días de pronóstico.
5. Ingresar un valor de 0 en el campo de entrada y verificar que aparezca el mensaje "El pronóstico admite entre 1 y 16 días." y que el valor se reajuste a 1 día.
6. Ingresar un valor de 17 en el campo de entrada y verificar que aparezca el mensaje "El pronóstico admite entre 1 y 16 días." y que el valor se reajuste a 16 días.

## Comando(s) de ejecución
```bash
npx playwright test qa/casos/jc/TC-JC-002/TC-JC-002.spec.ts --config=qa/playwright.config.ts --project=jc
```

## Resultado esperado
Con 1 y 16 días la API responde 200 y la interfaz muestra exactamente esa cantidad de días.
Con valores <1 o >16, el sistema restablece el valor al límite permitido (1 o 16) y muestra: "El pronóstico admite entre 1 y 16 días."
Por defecto se cargan 7 días.

## Resultado obtenido
La prueba se ejecutó con éxito. Se verificó que por defecto la aplicación carga 7 días de pronóstico. Al cambiar el input a 1 día y a 16 días, la aplicación consultó la API con el parámetro `forecast_days` correspondiente y renderizó exactamente 1 y 16 tarjetas de días. Al intentar ingresar 0 y 17 días, la interfaz mostró el mensaje de error de validación "El pronóstico admite entre 1 y 16 días." y reajustó automáticamente el valor a los límites 1 y 16 respectivamente.
