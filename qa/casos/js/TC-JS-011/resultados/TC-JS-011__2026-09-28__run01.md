## Paso a paso ejecutado

2. Navegar a la página principal del ambiente desplegado.
3. Escribir `<script>alert(1)</script>` en el campo de búsqueda de ciudad.
4. Esperar el procesamiento de la consulta y la respuesta del estado de búsqueda.
5. Verificar que ningún diálogo ni ejecución de script arbitrario ocurra en la ventana.
6. Verificar que el texto reflejado en el mensaje de "no se encontraron ubicaciones" sea renderizado en modo texto plano escapado.
7. Verificar que el conteo de elementos `<script>` inyectados en el DOM sea 0.

## Resultado esperado
No se ejecuta ningún script. El texto aparece escapado dentro del mensaje "No se encontraron ubicaciones para «<script>alert(1)</script>»" o similar, sin que el navegador lo interprete como HTML.

Prueba ejecutada de forma exitosa. No se disparó ningún diálogo ni ejecución de script. El texto reflejado se mostró como entidad escapada en el DOM (`&lt;script&gt;alert(1)&lt;/script&gt;`) dentro del elemento de estado (`.city-search__status`), y no se generó ninguna etiqueta `<script>` en la estructura del documento.

## Observaciones
El motor de interpolación y reconciliación de React (JSX) escapa de forma predeterminada las expresiones inyectadas en `{state.query}`, impidiendo la interpretación de HTML y mitigando ataques de XSS reflejado por inyección directa de cadenas en la vista.
