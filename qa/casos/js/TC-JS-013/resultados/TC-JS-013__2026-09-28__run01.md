## Descripción del caso de prueba
- RF relacionado: RNF-04 (Accesibilidad y calidad) / WCAG 2.1 AA
- Tipo de prueba: Accesibilidad
- Objetivo: Verificar el cumplimiento de umbrales automáticos de accesibilidad (RNF-04).
- Precondiciones: App desplegada en ambiente QA https://app-clima-local.vercel.app; Playwright con integración `@axe-core/playwright` configurado.

## Ambiente
- Nombre: QA
- URL: https://app-clima-local.vercel.app
- Commit / versión evaluada: main-preview
- Herramienta: Playwright

## Paso a paso ejecutado
1. Navegar a la página de inicio y auditar con axe-core el flujo de búsqueda y control de geolocalización.
2. Ingresar y seleccionar la ciudad «Bogotá» y auditar el flujo de clima actual y pronósticos.
3. Desplegar el selector de preferencias y auditar la configuración de unidades y modelos numéricos.
4. Cambiar a la pestaña «Comparar ciudades» y auditar el flujo interactivo de comparación.
5. Cambiar a la pestaña «Históricos» y auditar el formulario y estado de históricos meteorológicos.
6. Cambiar a la pestaña «Calidad del aire» y auditar el panel de contaminantes atmosféricos y escala AQI.
7. Validar que en cada uno de los 6 flujos no se presenten violaciones con nivel de severidad `critical` o `serious`.

## Comando(s) de ejecución
```bash
npm run qa:test:js -- qa/casos/js/TC-JS-013/TC-JS-013.spec.ts
```

## Resultado esperado
Lighthouse Accessibility ≥ 90 en cada flujo; axe-core reporta 0 violaciones de impacto critical o serious en cada flujo.

## Resultado obtenido
Auditoría superada exitosamente en el 100% de los flujos de la aplicación.
- Total flujos evaluados: 6
- Violaciones críticas (`critical`): 0
- Violaciones serias (`serious`): 0
- Violaciones moderadas (`moderate`): 0
- Violaciones menores (`minor`): 0
Todas las vistas evaluadas cumplen con las directrices de accesibilidad web WCAG 2.0 y 2.1 en los niveles A y AA.
