# TC-JS-012 — Privacidad de coordenadas en geolocalización

## Descripción del caso de prueba
- RF relacionado: RF-03 (Detección automática por geolocalización) / RNF-07 (Privacidad y protección de datos)
- Tipo de prueba: Seguridad
- Objetivo: Verificar que las coordenadas no se persisten, no se envían a analítica y que se muestra aviso previo (RNF-07).
- Precondiciones: App cargada; contexto de navegador con geolocalización simulada (lat=2.93, lon=-75.28); ambiente QA https://app-clima-local.vercel.app operativo.

## Ambiente
- Nombre: QA
- URL: https://app-clima-local.vercel.app
- Commit / versión evaluada: main-preview
- Herramienta: Playwright

## Paso a paso ejecutado
1. Verificar que existe aviso visible sobre el uso y no persistencia de la ubicación previo a solicitar permiso.
2. Simular permiso concedido y coordenadas (lat=2.93, lon=-75.28) y hacer clic en «Usar mi ubicación».
3. Auditar llamadas salientes de red (Network): validar que solo se dirijan a Open-Meteo y ninguna a servicios de analítica de terceros.
4. Inspeccionar almacenamiento (`localStorage` y `sessionStorage`): validar que las coordenadas numéricas no queden almacenadas.
5. Inspeccionar consola del navegador: verificar que no se emitan logs con las coordenadas del usuario.

## Comando(s) de ejecución
```bash
npm run qa:test:js -- qa/casos/js/TC-JS-012/TC-JS-012.spec.ts
```

## Resultado esperado
Aviso presente; coordenadas solo en llamadas a Open-Meteo; no persistidas en localStorage ni enviadas a terceros; sin logs de coordenadas.

## Resultado obtenido
Prueba superada con éxito en todos sus criterios de aceptación:
- **Aviso:** Presente y legible antes de la acción: *«Tu ubicación se utilizará únicamente para consultar información meteorológica y no se guardará.»*
- **Tráfico:** Se generó únicamente 1 petición con coordenadas hacia `api.open-meteo.com/v1/forecast`. Cero llamadas a servicios de telemetría o analítica externa.
- **Almacenamiento:** `sessionStorage` permanece completamente vacío `{}`; `localStorage` contiene únicamente la clave de unidades meteorológicas `weather-app.units`, sin registro de latitud, longitud ni identificadores de ubicación.
- **Consola:** Cero mensajes o errores emitidos con los valores de coordenadas.
