## Paso a paso ejecutado
1. Escanear el contraste de color con las reglas oficiales `color-contrast` de `axe-core` en vistas con datos meteorológicos cargados.
2. Comprobar que elementos clave (semáforo AQI, botones de modo activo y mensajes de error) aporten información textual explícita (`aria-label`, texto legible de categoría, `aria-pressed`) sin depender exclusivamente del cambio de matiz de color.
3. Configurar viewport móvil angosto a 320 px con factor de escala 2 (emulando 200% de aumento) y evaluar si existe desbordamiento horizontal de página (`scrollWidth > clientWidth`).
4. Simular la preferencia de usuario `prefers-reduced-motion: reduce` y verificar que las transiciones CSS queden deshabilitadas (`transition-duration: 0s`).
5. Auditar la etiqueta raíz `html` para comprobar `lang="es"` y revisar que los contenidos de la interfaz se presenten en español.

## Comando(s) de ejecución
```bash
npm run qa:test:js -- qa/casos/js/TC-JS-016/TC-JS-016.spec.ts
```

## Resultado esperado
Contraste cumple; información no depende solo del color; sin scroll horizontal a 320 px ni 200%; reduced motion respetado; 100% textos externalizados.

## Resultado obtenido
Prueba superada en todos sus criterios técnicos:
1. **Contraste cromático:** axe-core reportó 0 violaciones de contraste en texto y componentes (ratio ≥ 4.5:1 en texto estándar y ≥ 3:1 en componentes e indicadores de foco).
2. **Información no solo por color:** El panel de calidad del aire complementa el indicador cromático con el valor numérico, el nombre de la categoría textual (*«Moderada»*, *«Buena»*, etc.) y un `aria-label` descriptivo. Los botones de modo señalan su activación vía `aria-pressed="true"`.
3. **Reflow a 320 px / 200% Zoom:** Se verificó que `scrollWidth === clientWidth` a 320 px de ancho de viewport. Todo el layout colapsa verticalmente sin generar barra de desplazamiento horizontal ni solapamiento de información.
4. **Reduced Motion:** Bajo la media query `prefers-reduced-motion: reduce`, la duración computada de las transiciones se reduce a `0s`.
5. **Idioma y textos:** El documento declara `<html lang="es">` y la totalidad de los textos visibles de navegación, etiquetas y métricas se presentan en idioma español.
