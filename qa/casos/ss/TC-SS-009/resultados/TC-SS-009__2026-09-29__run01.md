# TC-SS-009 — Degradación controlada: ubicación sin cobertura (AQI nulo) y contaminante individual nulo

## Datos del evaluador
- Nombre: Sara Sofía González Gómez
- Rol / bloque: ss
- Fecha de ejecución: 2026-09-29
- N.º de ejecución (run): 01

## Descripción del caso de prueba
- RF relacionado: RF-06 (Calidad del aire)
- Tipo de prueba: Funcional
- Objetivo: Verificar que, si la ubicación no tiene datos de calidad del aire (AQI nulo) o un contaminante llega nulo, la aplicación lo informe de forma controlada sin romper la sección ni el resto de la app.
- Precondiciones: Ubicación activa: Neiva. Interceptación de /v1/air-quality con Playwright configurada para cada escenario. Panel de clima actual (RF-01) cargado.

## Ambiente
- Nombre: QA
- URL: https://app-clima-local.vercel.app
- Commit / versión evaluada: 66860ed (origin/main)
- Herramienta: Playwright 1.63.0 (Chromium build 1243)

## Datos de entrada
- Escenario A: todos los campos `current.*` = null (sin cobertura).
- Escenario B: `current.us_aqi = 42` y `current.sulphur_dioxide = null`; resto con valores válidos.
- Escenario C: `hourly.us_aqi` con 3 posiciones null dentro de las 24 h (02:00, 10:00, 20:00).

## Paso a paso ejecutado
0. Seleccionar Neiva, Huila como ubicación activa y esperar que cargue el panel de clima actual (RF-01). Interceptar /v1/air-quality con Playwright según el escenario (un test por escenario).
1. Escenario A (todos los current.* = null): abrir «Calidad del aire» y verificar el mensaje.
2. Verificar que la pestaña «Clima» (clima de Neiva) y la búsqueda de ciudades siguen operativas.
3. Escenario B (current.us_aqi = 42 y current.sulphur_dioxide = null): verificar «N/D» en SO₂, AQI 42 «Buena» y los demás contaminantes iguales a la respuesta.
4. Escenario C (hourly.us_aqi nulo en 3 horas dentro de las 24 h): verificar que la tendencia se muestra completa y que las horas nulas se señalan como N/D y no como 0.
5. Revisar la consola (pageerror y console.error): sin errores no controlados.

## Comando(s) de ejecución
```bash
npx playwright test --config=qa/playwright.config.ts qa/casos/ss/TC-SS-009 --project=ss
```

## Resultado esperado
- A: «La calidad del aire no está disponible para esta ubicación.» El resto de la app sigue operativa.
- B: «N/D» solo en SO₂; AQI 42 con categoría «Buena» y demás contaminantes normales.
- C: la tendencia se dibuja sin romperse; las horas nulas no se muestran como 0.

En ningún escenario aparece «null», «NaN» o una sección en blanco, ni errores no controlados en consola.

3/3 tests aprobados.

**Escenario B:** AQI 42, categoría «Buena».

| Contaminante | Respuesta | UI |

| sulphur_dioxide | null | N/D |
