# Corrección BUG-007 — Icono de categoría US AQI

- **Hallazgo QA:** TC-SS-007, reportado el 28/09/2026 sobre el build `50b9bc7`: el indicador de calidad del aire mostraba el valor, la categoría y el color, pero carecía de icono.
- **Causa raíz:** `AirQualityPanel` renderizaba únicamente el texto de `category.label` dentro del indicador y aplicaba el nivel a estilos de color. La utilidad ya entregaba el nivel semántico, pero no existía un componente gráfico ni una rama de renderizado que lo representara como icono.
- **Corrección:** la categoría del US AQI actual incorpora un pequeño medidor SVG. La posición de la aguja corresponde a uno de los seis niveles de la utilidad `getUsAqiCategory`. El icono utiliza el color semántico ya existente y acompaña al texto; no cambia la clasificación, el número, el mensaje ni los datos de contaminantes.
- **Accesibilidad:** el SVG es decorativo (`aria-hidden="true"`, `focusable="false"`). El grupo conserva su nombre accesible con el valor y la categoría; el significado sigue disponible sin interpretar el color o el icono. Si no hay AQI válido, se conserva el estado «no disponible».
- **Pruebas añadidas:** seis casos de componente comprueban la presencia visible del SVG junto al texto para las seis categorías; un caso E2E reproduce Bogotá con AQI 58 y comprueba «Moderada», el icono visible y el nombre accesible del indicador.
- **Verificación local:** `npm test`: 16 archivos, 364/364 pruebas aprobadas. `npm run lint`: salida 0. `npm run build`: salida 0; incluye TypeScript y Vite. `npm run test:e2e`: 8/8 aprobadas. El caso específico de BUG-007 también pasó a 320 px sin desplazamiento horizontal global. Auditoría estática de UI en modo estricto: 0 hallazgos. `git diff --check`: salida 0.

Los documentos de QA ya entregados en `docs/testing/` no se modifican. QA debe repetir TC-SS-007 sobre la versión publicada para cerrar el hallazgo de forma independiente.
