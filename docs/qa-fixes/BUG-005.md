# Corrección BUG-005 — Enlace para saltar al contenido principal

- **Hallazgo QA:** TC-JS-014, reportado el 28/09/2026 sobre el build `a6d5744`: el primer Tab llegaba al campo de búsqueda y no se observaba un enlace para omitir el bloque inicial.
- **Estado encontrado en el código actual antes de este ajuste:** ya existía un enlace al inicio del DOM con destino `#main-content` y un `<main id="main-content" tabindex="-1">`; su texto visible era `Saltar al contenido`, distinto del nombre esperado por el caso QA. La evidencia de QA corresponde a un build anterior y no permite afirmar que el enlace faltara en el código actual.
- **Causa raíz (alcance verificable):** no se pudo determinar con el código revisado por qué el build `a6d5744` no ofrecía el enlace en la prueba de QA. En la versión examinada para la corrección, el enlace sí existía; la discrepancia comprobable era su nombre (`Saltar al contenido` en lugar de `Saltar al contenido principal`) y que la regla visual lo revelaba solo con `:focus-visible`. La corrección cubrió ambos puntos sin atribuir al build reportado una causa que no quedó demostrada.
- **Corrección:** el nombre visible y accesible es ahora `Saltar al contenido principal`. El estilo revela el enlace cuando recibe foco por teclado o por otra forma de enfoque. Se mantiene su posición inicial en el orden del DOM y el destino principal enfocable.
- **Regresión automatizada:** la prueba de estructura confirma nombre y destino. Una prueba E2E en Chromium comprueba que el primer Tab enfoca el enlace, que se ve dentro del viewport y que Enter mueve el foco a `<main>` con la URL en `#main-content`.
- **Verificación local:** `npm test`: 16 archivos, 353/353 pruebas aprobadas. `npm run lint`: salida 0. `npm run build`: salida 0, TypeScript y Vite correctos. `npm run test:e2e`: 6/6 aprobadas. Auditoría estática de UI en modo estricto: 0 hallazgos.
- **Documentación anterior:** los documentos entregados a QA permanecen sin cambios. Esta nota registra el ajuste y la evidencia posterior.

**Estado de corrección:** implementada y verificada localmente. QA debe repetir TC-JS-014 en el build actualizado para cerrar el hallazgo de forma independiente.
