# Corrección BUG-006 — Comparación histórica y clima actual

- **Hallazgo QA:** TC-SS-005, reportado el 28/09/2026 sobre el build `cf54d9e`: no se encontraba una forma de comparar la fecha histórica consultada con otra fecha o con el clima actual.
- **Estado encontrado antes de este ajuste:** la versión actual ya permitía comparar dos fechas históricas tras consultar un solo día, y tenía pruebas de componente y E2E para ese recorrido. No ofrecía la comparación con el clima actual. El build del hallazgo es anterior a esta revisión.
- **Corrección:** la sección de comparación de un día permite elegir «Otra fecha histórica» o «Clima actual». La primera conserva la segunda consulta Archive. La segunda consulta Forecast únicamente tras pulsar «Comparar con clima actual», usando la misma ubicación y unidades. La tabla presenta ambos valores con fecha y hora local, diferencia con signo y unidad, y `N/D` para datos ausentes. No se solicita Forecast al cambiar solo el selector.
- **Semántica de los datos:** se muestran temperatura media, humedad media, precipitación acumulada y viento máximo históricos junto a las respectivas mediciones actuales. La pantalla advierte que los resúmenes diarios y las mediciones actuales corresponden a periodos distintos. La diferencia se calcula como valor histórico menos valor actual; es una comparación aritmética, no una equivalencia temporal.
- **Concurrencia:** al cambiar de modo, ubicación, fecha base o unidades, la comparación anterior deja de ser visible y las solicitudes pendientes se cancelan mediante la lógica existente de los hooks. Los errores conservan el catálogo E-01 a E-05 y permiten reintentar, salvo E-03.
- **Pruebas añadidas:** comportamiento explícito de ambas opciones, parámetros y resultado de Forecast, diferencias con signo, nulos, cambio de unidades, cancelación de respuesta tardía, error y reintento. La prueba E2E de TC-SS-005 recorre Neiva, 15/09/2026 frente a 15/09/2025 y luego frente al clima actual, con APIs interceptadas.
- **Verificación local:** `npm test`: 16 archivos, 358/358 pruebas aprobadas. `npm run lint`: salida 0. `npm run build`: salida 0; incluye TypeScript y Vite. `npm run test:e2e`: 7/7 aprobadas. La prueba específica de BUG-006 también pasó a 320 px sin desplazamiento horizontal global. Auditoría estática de UI en modo estricto: 0 hallazgos. `git diff --check`: salida 0.

Los documentos de QA entregados en `docs/testing/` no se modificaron. QA debe ejecutar nuevamente TC-SS-005 sobre la versión publicada para cerrar el hallazgo desde su evaluación independiente.
