# Corrección BUG-008 — US AQI no numérico

- **Hallazgo QA:** TC-SS-008, reportado el 28/09/2026 sobre el build `1237d41`. Una respuesta `current.us_aqi = "abc"` mostraba «La calidad del aire no está disponible para esta ubicación.» en vez de `N/D`.
- **Causa raíz:** `nullableNumber` normalizaba tanto el `null` real como cualquier valor no numérico a `null`. El panel solo examinaba `current.usAqi === null`, por lo que no podía distinguir un dato ausente de un dato inválido y elegía el mismo mensaje para ambos.
- **Corrección:** el modelo normalizado conserva `usAqiValidity` (`valid`, `missing`, `invalid`) junto al valor numérico seguro. `null` o una propiedad ausente mantienen el mensaje de indisponibilidad. Un valor no numérico, no finito o negativo se presenta como `N/D`, sin categoría ni icono. El valor crudo nunca se muestra. Los contaminantes válidos permanecen visibles. En la tendencia, los AQI horarios negativos o no numéricos también quedan como `null` y se muestran `N/D`.
- **Pruebas añadidas:** normalización de `"abc"`, `-1`, `null` y `0`; AQI horario inválido; componente con AQI inválido y contaminantes; reproducción E2E de TC-SS-008 con `/v1/air-quality` interceptado.
- **Verificación local:** `npm test`: 16 archivos, 370/370 pruebas aprobadas en la ejecución final. `npm run lint`: salida 0. `npm run build`: salida 0, con TypeScript y Vite correctos. `npm run test:e2e`: 9/9 aprobadas. La prueba E2E específica de BUG-008 también pasó por separado. Auditoría estática de UI en modo estricto: 0 hallazgos. `git diff --check`: salida 0.
