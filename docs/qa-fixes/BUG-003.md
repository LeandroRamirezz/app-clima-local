# Corrección BUG-003 — Cobertura incompleta del modelo ICON

- **Hallazgo QA:** TC-JC-006, reportado el 28/09/2026 con una respuesta HTTP 200 de Forecast para Neiva e ICON (`icon_seamless`) con `temperature_2m` y `weather_code` nulos.
- **Comportamiento reportado:** el panel mostraba `N/D` y `Condición no disponible`, sin explicar la falta de cobertura ni permitir regresar directamente a Automático.
- **Causa:** la interfaz contemplaba el rechazo HTTP 400 de un modelo, pero no distinguía una respuesta técnicamente válida con las dos variables principales del clima actual ausentes.
- **Corrección:** cuando un modelo elegido manualmente devuelve a la vez temperatura y código meteorológico actuales nulos, se muestra el texto de cobertura solicitado en una región `role="status"` y el botón `Volver a Automático`. Los demás datos disponibles permanecen visibles. El botón cambia `models` a `best_match` mediante el flujo Forecast existente, con su cancelación y protección de respuestas obsoletas. No se cambia automáticamente de modelo ante una respuesta HTTP 200 parcial.
- **Alcance de la condición:** el aviso no aparece para Automático ni por un solo dato nulo. Esta regla evita clasificar como ausencia de cobertura una variable aislada que falte.
- **Pruebas de regresión:** dos pruebas de componente cubren el aviso, datos disponibles, retorno a Automático y ausencia de aviso en los otros casos; una prueba E2E en Chromium intercepta Forecast para ICON, verifica el mensaje, la acción, el cambio de parámetro y el layout a 320 px.
- **Verificación local:** `npm test`: 16 archivos y 353/353 pruebas aprobadas. `npm run lint`: salida 0. `npm run build`: salida 0, TypeScript y Vite correctos. `npm run test:e2e`: 4/4 pruebas aprobadas. Auditoría estática de la skill de UI en modo estricto: 0 hallazgos.
- **Documentación anterior:** los documentos entregados a QA permanecen sin cambios. Esta nota registra una corrección posterior.

**Estado de corrección:** implementada y verificada localmente. QA debe repetir TC-JC-006 en el build actualizado para cerrar el hallazgo de forma independiente.
