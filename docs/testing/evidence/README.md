# Evidencia de Lighthouse

Los JSON son corridas locales del 29/09/2026 sobre `http://127.0.0.1:4173/`, servido por `npm run preview`. Se ejecutó Lighthouse 13.5.0 con Edge instalado; se solicitaron Performance, Accessibility y Best Practices. `lighthouse-mobile.json` registra el build previo a cargar las vistas secundarias bajo demanda (71/100/96); `lighthouse-desktop.json`, el build previo en escritorio (100/100/96). `lighthouse-mobile-after-split.json` y `lighthouse-mobile-after-split-2.json` registran dos corridas del **build actual** con idéntica emulación móvil y throttling: **100/100/96** y **68/100/96**. Esta variación impide afirmar un cumplimiento reproducible del umbral móvil >90. Cada JSON registra `finalDisplayedUrl`, `configSettings` y auditorías detalladas.

El CLI terminó con `EPERM` al intentar eliminar su perfil temporal de Windows tras escribir cada JSON; `runtimeError` del reporte está ausente. Por ello estos archivos son evidencia de las mediciones, pero los comandos no se registran como exitosos. Se conservan otras dos mediciones móviles anteriores (66 y 69) en [test-results.md](../test-results.md), sin sus JSON originales porque Playwright limpió el directorio temporal donde estaban. `e2e-report.json` es el reporte Playwright de la última ejecución de 2/2 casos aprobados.
